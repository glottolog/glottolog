# About Glottolog

## Catalogue of languages and families

Glottolog provides a comprehensive catalogue of the world's languages, language families and dialects. 
It assigns a unique and stable identifier (the [Glottocode](glossary.md#glottocode)) to (in principle) 
all languoids, i.e. all families, languages, and dialects. Any variety that a linguist works on should 
eventually get its own entry. The languoids are organized via a genealogical classification 
(the Glottolog tree) that is based on available historical-comparative research (see also the 
[Languoids information](languoids.md) section).


## Bibliography

The [References](../references/) section provides a comprehensive collection of bibliographical data 
for the world's lesser known languages. It provides access to references of descriptive works such as 
grammars, dictionaries, word lists, texts etc.

## Credit

Glottolog is collaborative work.

- Harald Hammarström collected many individuals' bibliographies and compiled them into a master bibliography.
- Harald also collected extensive information about the proved genealogical
  relations of the languages of the world. His top-level classification is merged
  with low-level (i.e. dialect level) information from many sources, including MultiTree.
- Sebastian Nordhoff designed and programmed the database and the first version of
  the web application with help from Hagen Jung and Robert Forkel. He also took
  care of the import of the bibliographies. 
- Robert Forkel programmed the second version of the web application as part of the
  [Cross Linguistic Linked Data](https://clld.org) project.
- Martin Haspelmath gave advice at every stage throughout the project, helped with 
  coordination, and is currently responsible for languoid names and dialects.
- Sebastian Bank made numerous improvements to the code base for the Glottolog website 
  and organized the import of several large bibliographies.
